# 🧩 GlassHub Engine - Component Library Catalog

This document serves as an exhaustive reference catalog for all UI components implemented in **GlassHub Engine**. Each component entry specifies its category, props interface, styling parameters, accessibility features, and code usage snippets.

---

## ⚛️ Atoms (UI Primitives)

### 1. `Button`
*Location:* `src/components/atoms/Button.tsx`  
*Description:* Universal button element supporting custom glass styling variants, loading spinners, and icon slots.

#### Props Interface
```typescript
interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'glow-primary' | 'glow-accent' | 'glass' | 'ghost' | 'danger';
  size?: 'sm' | 'md' | 'lg';
  isLoading?: boolean;
  leftIcon?: React.ReactNode;
  rightIcon?: React.ReactNode;
  children: React.ReactNode;
}
```

#### Usage Example
```tsx
import { Button } from './components/atoms/Button';
import { Sparkles } from 'lucide-react';

<Button
  variant="glow-primary"
  size="md"
  leftIcon={<Sparkles className="w-4 h-4" />}
  onClick={() => console.log('Action executed!')}
>
  Explore Hub
</Button>
```

### 2. `GlassCard`
*Location:* `src/components/atoms/GlassCard.tsx`  
*Description:* Primary glassmorphic container utilizing GPU backdrop blurs, subtle border highlights, and optional hover tilt animations.

#### Props Interface
```typescript
interface GlassCardProps extends React.HTMLAttributes<HTMLDivElement> {
  variant?: 'default' | 'subtle' | 'interactive' | 'glowing';
  glowColor?: 'cyan' | 'purple' | 'amber' | 'emerald';
  children: React.ReactNode;
  className?: string;
}
```

#### Usage Example
```tsx
import { GlassCard } from './components/atoms/GlassCard';

<GlassCard variant="interactive" glowColor="cyan" className="p-6">
  <h3 className="text-xl font-bold text-white">Crystalline Engine</h3>
  <p className="text-slate-300">High-performance translucent design system.</p>
</GlassCard>
```

---

### 3. `GlassModal`
*Location:* `src/components/atoms/GlassModal.tsx`  
*Description:* Portal dialog component mounted directly to `document.body` via `React.createPortal`. Features body scroll-locking, backdrop blur, `Esc` keyboard dismissal, and backdrop click handlers.

#### Props Interface
```typescript
interface GlassModalProps {
  isOpen: boolean;
  onClose: () => void;
  title?: string;
  maxWidth?: 'sm' | 'md' | 'lg' | 'xl' | '2xl';
  children: React.ReactNode;
}
```

#### Usage Example
```tsx
import { GlassModal } from './components/atoms/GlassModal';

<GlassModal isOpen={isModalOpen} onClose={() => setIsModalOpen(false)} title="System Details">
  <div className="p-4 text-slate-200">
    <p>Modal content rendered cleanly outside parent z-index boundaries.</p>
  </div>
</GlassModal>
```

---

### 4. `GlassErrorBoundary`
*Location:* `src/components/atoms/GlassErrorBoundary.tsx`  
*Description:* Class-based React Error Boundary that catches component render crashes and presents a cosmic recovery card with a manual reset trigger.

#### Props Interface
```typescript
interface GlassErrorBoundaryProps {
  children: React.ReactNode;
  onReset?: () => void;
}
```

---

### 5. `Heading` & `Text`
*Location:* `src/components/atoms/Heading.tsx` & `src/components/atoms/Text.tsx`  
*Description:* Typography primitives standardizing gradient text, semantic tags (`h1`-`h6`, `p`, `span`), and responsive typography scales.

```tsx
<Heading level="h2" gradient="cosmic">Cosmic Architecture</Heading>
<Text variant="muted" size="lg">Decoupled atomic components built for resilience.</Text>
```

## 🧪 Molecules (Composite Components)

### 1. `PixQrCustom`
*Location:* `src/components/molecules/PixQrCustom.tsx`  
*Description:* High-precision QR code renderer embedding an inner SVG logo, custom rounded corner modules, and linear gradients powered by `qr-code-styling`.

#### Props Interface
```typescript
interface PixQrCustomProps {
  data: string; // The EMV payload string generated by pix.ts
}
```

---

### 2. `PixModal` & `PixQrModal`
*Location:* `src/components/molecules/PixModal.tsx` & `src/components/molecules/PixQrModal.tsx`  
*Description:* Interactive dynamic payment modals allowing users to select or input custom support amounts, compute valid EMV BR Code payloads in real time, view high-res QR codes, and copy payloads with 1-click clipboard feedback.

---

### 3. `PayPalDonateButton`
*Location:* `src/components/molecules/PayPalDonateButton.tsx`  
*Description:* Integrates PayPal Checkout SDK asynchronously. Automatically loads official SDK scripts and renders native checkout triggers without breaking glass aesthetics.

---

### 4. `ArticleCard`
*Location:* `src/components/molecules/ArticleCard.tsx`  
*Description:* Displays article summaries, read-time estimates, tags, publication date, and triggers full-page reading mode.

---

### 5. `ProjectCard`
*Location:* `src/components/molecules/ProjectCard.tsx`  
*Description:* Displays project showcase items with repository badges, live preview links, and technology stack tags.

---

### 6. `CosmicBackground`
*Location:* `src/components/molecules/CosmicBackground.tsx`  
*Description:* Canvas & CSS animation container providing floating cosmic dust particles, glowing ambient nebulae, and gradient meshes.

## 🔬 Organisms (Full Feature Sections)

### 1. `Header`
*Location:* `src/components/organisms/Header.tsx`  
*Description:* Top sticky navigation header featuring the animated GlassHub brand widget, section navigation links, i18n language toggle switch, and mobile drawer modal.

### 2. `HeroSection`
*Location:* `src/components/organisms/HeroSection.tsx`  
*Description:* Entrance hero banner showcasing cosmic title gradients, interactive platform metrics, call-to-action buttons, and status badges.

### 3. `AboutMeSection` & `AboutGlassHubSection`
*Location:* `src/components/organisms/AboutMeSection.tsx` & `src/components/organisms/AboutGlassHubSection.tsx`  
*Description:* Deep narrative sections detailing professional engineering milestones, technical principles, and architectural vision.

### 4. `ArticleReaderPage`
*Location:* `src/components/organisms/ArticleReaderPage.tsx`  
*Description:* Full-screen reader view for Markdown technical articles. Parses content dynamically, renders structured headings, builds an automated table of contents, and supports clean URL routing.

### 5. `ContributionSection`
*Location:* `src/components/organisms/ContributionSection.tsx`  
*Description:* Crowdfunding and support hub combining Pix dynamic payments, PayPal integration, and Patreon support tiers.
